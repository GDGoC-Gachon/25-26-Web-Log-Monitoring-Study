| 항목 | 내용 |
|------|------|
| 상태 | 부분 구현 |
| 단계 | 1차 |
| 우선순위 | P0 |

| 관련 이슈 | 시연 배포 환경과 저장소 예시 설정의 경로 목록 차이 확인 필요 |

## 요구사항

| ID | 요구사항 | 상태 |
|----|----------|------|
| REQ-PATH-001 | 최근 조회 구간에서 민감 경로 접근 시도를 탐지해야 한다. | 구현됨 |
| REQ-PATH-002 | 요청 경로가 설정 경로와 정확히 일치하거나 그 하위 경로이면 대소문자와 관계없이 탐지해야 한다. | 구현됨 |
| REQ-PATH-003 | 민감 경로 목록은 `SENSITIVE_PATHS` 환경 변수로 관리해야 한다. | 구현됨 |
| REQ-PATH-004 | 결과에는 `clientIp`, 요청 경로, 일치한 민감 경로, 발생 수, 조회 창을 포함하고 원본 로그에 존재하는 `hostDomain`을 보존해야 한다. | 부분 구현 |
| REQ-PATH-005 | 배포 환경의 관리·어드민·마스터 경로 목록을 기록하고 실제 활성 설정으로 회귀 QA해야 한다. | QA 필요 |

## 수용 기준

- 설정이 `/admin`이면 `/admin`, `/admin/`, `/admin/users?tab=active`를 탐지한다.
- `/administrator`처럼 경계가 다른 경로는 `/admin`의 하위 경로로 오인하지 않는다.
- 같은 IP와 경로라도 `hostDomain`이 다르면 별도 결과로 유지한다.
- `/.env`, `/admin`, `/master`는 실제 배포 설정에 포함된 경우 각각 시연 테스트를 수행한다.

## QA 메모

저장소 기본값은 `/.env,/admin`이고 `.env.example`은 여기에 `/wp-admin,/phpmyadmin`을 추가한다. 회의에서 언급된 `/master` 등은 배포 설정에 존재하는지 확인한 뒤 예시 설정 변경 여부를 결정한다.
