# DDoS 의심 탐지 요구사항

| 항목 | 내용 |
|------|------|
| 상태 | 부분 구현 |
| 단계 | 1차 |
| 우선순위 | P0 |
| 대상 코드 | `src/jobs/DDos.job/job.ts` |
| 현재 차이 | 도메인별 요청 수가 기본 메일 본문과 수신자 판정에 사용되지 않음 |

## 요구사항

| ID | 요구사항 | 상태 |
|----|----------|------|
| REQ-DDOS-001 | `DETECTION_WINDOW_MINUTES`로 지정한 최근 로그를 조회해야 한다. | 구현됨 |
| REQ-DDOS-002 | 동일 `clientIp`의 전체 요청 수를 계산해야 한다. | 구현됨 |
| REQ-DDOS-003 | 동일 `clientIp` 안에서 `hostDomain`별 요청 수도 함께 계산해야 한다. | 구현됨 |
| REQ-DDOS-004 | 전체 요청 수가 `DDOS_REQUESTS_PER_IP` 이상이면 DDoS 의심 IP로 판단해야 한다. | 구현됨 |
| REQ-DDOS-005 | `DDOS_EXCLUDED_IPS`에 여러 예외 IP를 등록할 수 있어야 한다. | 구현됨 |
| REQ-DDOS-006 | 예외 IP는 전체 및 도메인별 집계에서 제외해야 한다. | 구현됨 |
| REQ-DDOS-007 | 결과에 `clientIp`, 전체 요청 수, 임계값, 조회 창, `hostDomain`별 요청 수를 포함해야 한다. | 구현됨 |
| REQ-DDOS-008 | 알림에는 대상 `hostDomain`별 요청 수를 표시하고 서비스 사용자에게 노출할 범위는 승인된 다중 도메인 정책을 따라야 한다. | 계획 |

## 수용 기준

| ID | 시나리오 | 기대 결과 |
|----|----------|-----------|
| AC-DDOS-001 | 한 IP가 A 200회, B 101회 요청. 임계값 300 | 전체 301회로 탐지하고 A 200, B 101을 보존 |
| AC-DDOS-002 | 예외 IP가 임계값 초과 | 미탐지 |
| AC-DDOS-003 | 여러 도메인에 걸친 탐지 메일 | 운영자는 전체와 도메인별 건수를 확인하고 서비스 사용자는 승인 범위만 확인 |
